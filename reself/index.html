WHAT · 무엇을

특별교육의 표준화

가해학생 특별교육을 AI 기반 표준 교육과정으로 전환하고, 조치 이행관리 플랫폼을 함께 제공합니다.

WHY · 왜

조치 이후가 비어 있다

훈계·강의 중심 교육은 효과가 약하고, 조치 이후 변화를 추적하는 체계가 없습니다. 교사 행정부담과 학부모 불복은 커지고 있습니다.

HOW · 어떻게

표준 모듈 + MIRROR + 대시보드

PRE / LIGHT / CORE / INTENSIVE 표준 모듈, 학생앱 MIRROR, 교육청 이행관리 대시보드로 구성됩니다.

WHO · 누구에게

제17조 특별교육 대상

「학교폭력예방법」 제17조에 따른 특별교육·심리치료 대상 가해학생과 보호자. 1차 시범은 5호 조치 학생과 보호자입니다.

새로운 수요를 만드는 사업이 아니라, 이미 집행되고 있는 예산의 집행 방식을 바꾸는 사업입니다.

PART 01 · 문제 정의

교육은 이수되지만,
변화는 확인되지 않는다

학교 현장의 3중 딜레마. Re:SELF는 이 셋을 ‘조치 이후가 비어 있다’는 하나의 구조적 공백으로 봅니다.

01

교원 업무 · 민원 부담

사안 조사 · 조치 이행관리 · 결과 보고가 교사에게 집중됩니다. 민원과 불복에 개인이 노출되면서 학교는 형식적 처리로 후퇴합니다.

교사 1인당 학폭 이행관리 월 평균 8~15시간 (현장 조사 기준)

02

학생 인권

가해학생도 교육 대상이라는 원칙과 실제 운영 사이의 간극이 큽니다. 낙인은 남고 변화는 없는 교육은 재발도 막지 못합니다.

03

보호자 저항

정보 비대칭과 낙인감이 “우리 애 말은 안 들어줬다”로 이어집니다. 학교가 하는 말은 설득력을 갖기 어렵습니다.

PART 02 · 솔루션

AI Companion이 아니라
통제된 교육도구

‘미성년자 × 자유형 AI 대화 × 정서적 주제’는 지금 규제가 가장 강하게 반대하는 조합입니다. Re:SELF는 교육 목적 · 세션 시간 · 인간 감독이 모두 통제된 학교 운영 교육도구입니다.

원칙 1

교육 목적 제한

정해진 모듈 안에서만 분기. 자유대화 금지.

원칙 2

세션 제한

교육기간 · 지정 세션에만 접근. 24시간 접근 불가.

원칙 3

학교 계정

개인 가입 없음. 교사 발급 1회용 코드만 유효.

원칙 4

인간 감독

교사 배석. 위기 발화는 즉시 교사에게 전달.

원칙 5

AI 판정 금지

성격 · 위험도 진단 없음. 질문으로만 구조화.

LAYER 1

MIRROR · 학생 성찰 앱

  • 낙인 없는 중립 UI — 화면만 봐서는 용도를 알 수 없다
  • 사건 돌아보기 · 입장 바꾸기 · 행동 리허설 · 재발방지 계획
  • 교육 종료 시 학생이 직접 삭제 버튼을 누른다
LAYER 2

Re:SELF 교육과정

  • PRE / LIGHT / CORE / INTENSIVE 4개 트랙
  • 온라인 성찰 세션 + 오프라인 실습 혼합
  • 심의위원회가 정한 시간에 맞춰 모듈 조합
  • 강사 매뉴얼 · 표준 커리큘럼 동반
LAYER 3

이행관리 대시보드

  • 조치별 이수 진행률 · 보호자 동반 이수 현황
  • 이수확인서 · 이행 증빙 자동 생성
  • 4주 · 8주 추적 자동 알림
  • 비식별 통계만 상급기관으로 집계

데이터 원칙 : Create → Reflect → Report → Destroy

미성년자 · 학교폭력이라는 민감 맥락에서 개인정보 설계는 부가기능이 아니라 핵심 경쟁력입니다.

CREATE · 생성
  • 학생이 고른 자료만 최소 수집
  • 제3자 정보 자동 마스킹
  • 원본과 성찰 프로필 분리 저장
REFLECT · 성찰
  • 교육기간에만 유효한 계정
  • 대화 기록 암호화 · 권한 분리
  • 교사에게 원문 전체 비공개
REPORT · 산출
  • 학생이 승인한 내용만 기록
  • 학생 작성 / 학생 승인 / AI 요약 구분 표기
  • 징계 · 사실판단 자료 사용 금지
DESTROY · 폐기
  • 사진 · 원본 · 대화원문 삭제
  • 학생이 직접 누르는 삭제 의식
  • 비식별 교육효과 통계만 잔존
