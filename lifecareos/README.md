# Life CareOS — Private AI 돌봄 운영체제 (데모)

복지관·지자체 내부에 설치되는 **Private AI Agent**가 흩어진 기록을 한 사람에 대한 이해(**Life Care Profile**)로 바꾸고,
사회복지사에게 질문·상담·방문·프로그램·연계의 우선순위를 제안하는 돌봄 운영체제 데모입니다.

> 사업계획서 `LifeCareOS.pptx`를 바탕으로 만든 인터랙티브 데모입니다. 모든 인물·기록은 **가상 데이터**입니다.

## 화면

| 파일 | 설명 |
|---|---|
| [`index.html`](index.html) | 제품 소개 랜딩 — 문제 → 6개 제품 → 9개 축 → 로컬 처리 구조 → 시장 |
| [`app.html`](app.html) | **돌봄 운영 콘솔** — 사회복지사가 실제로 쓰는 6개 모듈 인터랙티브 데모 |

## 6개 제품 (콘솔 좌측 메뉴)

| | 제품 | 데모에서 할 수 있는 것 |
|---|---|---|
| **P1** | Life Care Starter | 샘플 자료 8건을 올리고 AI가 5단계로 자동 분류(9개 축 배정)하는 과정 재생 |
| **P2** | Profile Agent | 9개 축 통합 프로파일 · 커버리지 매트릭스 · **근거 추적**(항목→원문 문장) |
| **P3** | Persona Agent | 주·부 유형 진단, 추정 근거, 낙인 방지 원칙 |
| **P4** | Question Agent | 적응형 추천 질문 — **답변을 기록하면 완성율이 오르는 순환(P4→P2→P5)** |
| **P5** | Decision Agent | 오늘의 우선순위 큐 — 신호·제안·우선순위, 제안 실행·기록 |
| **P6** | Life Archive | 생애 타임라인 · Life Book · 지역 아카이브 확장 |

## 핵심 인터랙션

- **순환 구조(↻)** — P5에서 제안을 "실행·기록"하거나 P4에서 질문에 답하면 프로파일 완성율이 오르고 다음 추천이 조정됩니다.
- **근거 추적** — 프로파일의 각 항목에서 `🔗 근거`를 누르면 어느 문서 어느 문장에서 추출됐는지 원문이 열립니다.
- **로컬 처리** — 원문은 기관 내부에, 중앙에는 비식별 성과만 — 화면 곳곳에 🔒 로 표시.

## 기술

순수 정적 HTML/CSS/JS(빌드 불필요, 의존성 없음). GitHub Pages에서 그대로 동작합니다.
글꼴은 Pretendard(jsDelivr CDN), 그 외 모든 로직과 데이터는 `app.html`에 인라인 포함되어 있습니다.
